# Cheminement optimal dans les graphes

**Projet STDO - ENSIIE FISA 1A**

Eva GENTILHOMME, Arthur PINEL

## Objectif

Le but de ce projet est d’implémenter efficacement l’algorithme de Dijkstra permettant de calculer la
plus courte chaîne entre deux sommets dans un graphe non-orienté, sans boucle, ainsi que des variantes
qui permettent de diminuer le nombre de sommets visités sur des graphes de grande taille. Une structure
de tas sera utilisée pour la mise en œuvre de l’algorithme de Dijkstra
